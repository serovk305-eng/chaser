# Toyota Chaser — мод для Minecraft 1.20.1 (Forge 47)

## Что умеет
- Посадка ПКМ, до 2 человек (водитель справа — японский правый руль).
- W/S — газ/тормоз/задний ход, A/D — руль, ПРОБЕЛ — ручник (дрифт с дымом), SHIFT — выйти.
- Топливо: полный бак ≈ 1000 блоков. ПКМ канистрой по машине — +25% бака (4 заправки).
- Звук мотора: высота тона зависит от скорости.
- Покраска: ПКМ любым красителем по машине.
- HUD: скорость (км/ч) и топливо.
- Получить: креативная вкладка «Toyota Chaser» или крафт. Сломать машину — она выпадет предметом, топливо и цвет сохранятся.

## Крафт
Машина:  ряд 1 — 3 стеклянные панели; ряд 2 — железный блок, поршень, железный блок; ряд 3 — угольный блок, пусто, угольный блок.
Канистра: ряд 1 — _ железо _; ряд 2 — железо, угольный блок, железо; ряд 3 — 3 железа.

## Как собрать
1. Скачай Forge MDK 1.20.1 (47.3.0) с files.minecraftforge.net.
2. Скопируй из MDK в эту папку: gradlew, gradlew.bat и gradle/wrapper/gradle-wrapper.jar.
3. Запусти: gradlew runClient — тест в игре, gradlew build — готовый мод в build/libs/chaser-1.0.0.jar.
Нужна Java 17.

## Как вставить свою модель из Blockbench
1. Тип проекта — «Modded Entity». Перед машины смотрит на North (-Z), колёса стоят на Y=0.
2. Колёса — отдельные группы: wheel_fl, wheel_fr, wheel_rl, wheel_rr (точка вращения в центре колеса).
3. File -> Export -> Export Java Entity -> «Forge 1.17+ (Mojang mappings)».
4. Из экспорта скопируй тело createBodyLayer() в src/main/java/com/kostya/chaser/client/ChaserModel.java.
5. Текстуру положи в src/main/resources/assets/chaser/textures/entity/chaser.png.
   Кузов делай белым/светло-серым — цвет красителя умножается на текстуру.
